# Contributing

Small, focused contributions are welcome. Describe the scientific or usability change and include a reproducible example. Keep numerical changes separate from documentation-only changes.

For a bug report, include the Python/OpenFOAM version, operating system, command, parameters and relevant error output. Do not upload private datasets or credentials.

For numerical changes, include a convergence, invariant or reference-solution check where appropriate. Keep units, coordinate conventions and limitations explicit. Generated artwork should distinguish computed results from conceptual diagrams.
